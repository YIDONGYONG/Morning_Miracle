## READMEレビュー時から変更した機能
### 変更した機能
- 目標の自動下方修正 → 「一段階軽くしてみませんか？」と提案し、本人が選ぶ方式に変更
  （理由：システムが勝手に難易度を下げると、「できなかった」と責められている印象になりかねず、「挫折感や自己嫌悪をなくす」という目的に合わないと判断したため）
- ストリーク（連続達成日数）の可視化 → 「これまでに迎えた朝」の累計表示に変更
  （理由：連続記録は1日休むと0に戻り、READMEで課題とした既存アプリ（Streaks）と同じ問題が起きるため。累計は減らない）
- 人生の目標・ビジョンの保存先 → `users.life_vision` から、独立した `visions` テーブルに変更
  （理由：複数のビジョンを持て、タイトル・内容・達成予定日を個別に管理できるようにするため）
- パスワードの保存 → `crypted_password` / `salt` から、Rails標準の `has_secure_password`（`password_digest`）に変更
  （理由：追加の gem なしで、安全なハッシュ化を使えるため）

### 削除した機能
- 3日連続未達成時の自動降格（理由：上記のとおり、本人が選ぶ方式に置き換えたため）
- パスワードリセット・パスワード変更・メールアドレス変更・アカウント退会・お問い合わせ
  （理由：MVPの検証対象は「続けられるか」であり、アカウント管理は検証に不要と判断し、MVP後に回したため。READMEでも「MVP後」の扱い）

### 追加した機能

## レベルアップの仕組み（現在の実装）
- 「クリアした日」：4つのルーティンをすべて、最後までやった日。
- 「クリアした週」：1週間（月〜日）に、クリアした日が3日以上ある週。
- 同じレベルで「クリアした週」が2週続くと、レベルが1つ上がります（最大レベル8）。昇格した週は、新しいレベルの1週目には数えません。
- 1週間のクリアが0日の場合は、休み券（月2枚）で免除されます。券がなければ、「一段階軽くする」を提案します（選ぶのは本人です）。
- 判定は、アプリに接続したときに「先週」を一度だけ行います。

* level : 現在のレベル（1〜8。4つのルーティン共通）

Routines（ルーティン情報）

* category : enum（0:運動, 1:瞑想, 2:読書, 3:1日計画） / ユーザーごとにユニーク
* current_level : 現在のレベル（`users.level` と同期）
* last_recorded_on : 最後に記録した日

Routine_logs（日ごとの記録）
* routine_id : ルーティン / 外部キー
* recorded_on : 記録した日 / routine_id との複合ユニーク制約
* achieved : 達成したか（false は「休んだ日」）
* completed_fully : 最後までやったか（途中でやめた日は false。クリアした日には数えない）

Activity_logs（やってみた記録）
* user_id : ユーザー / 外部キー
* activity_key, kind, level : 種目・種類（timer / count / check）・そのときのレベル
* target_seconds, actual_seconds : 目標時間と、できた時間
* started_at, completed_at : 開始・完了時刻
* completed_fully : 最後までやったか

Visions（ビジョン）
* user_id : ユーザー / 外部キー
* title, content : タイトル（50文字まで）と内容（500文字まで）
* target_date : 達成予定日（今日以降）

Weekly_reviews（週ごとの振り返り）
* user_id : ユーザー / 外部キー
* week_start : 対象週の月曜日 / user_id との複合ユニーク制約
* clear_days : その週のクリアした日数
* outcome : promoted / stayed / exempted / suggested
* level_before, level_after : 判定前後のレベル
* acknowledged_at, responded_at, accepted : お知らせの確認、提案への返事

# 1. サービス概要

## どんなサービスか
厳格な管理ではなく、自らのペースで朝の成長を具現化する「適応型」ルーティン・習慣化アプリ。

## 誰の課題をどう解決するか
**対象：** 三日坊主を繰り返してしまう方へ。段階的なレベルアップで、無理なく習慣化できるアプリ。

**解決策：**
1. 3日連続で未達成の場合に自動で難易度を下げる「適応型セーフティネット」により、完璧主義による挫折とバーンアウトを防ぎます。
2. 厳格な統制ではなく「毎日の小さな成長」とスモールステップを重視し、自分のペースで持続可能な習慣を定着させます。

# 2. このアイデアはどこから生まれたか

## 2-1. きっかけとなった体験・感情
**背景：** 平日は仕事をしながら、夜は疲れた身体でプログラミング学習に取り組んでいました。しかし、疲労から学習に集中できず、思うように進捗を出せない日々が続いていました。その中で朝の時間を有効活用する方法を探していた際、『Atomic Habits（アトミック・ハビッツ）』や『ミラクルモーニング』などの自己啓発書に出会い、大きな影響を受けました。

**気づき：** これらの書籍を通じて、一流のCEOやアスリートが瞑想や運動などの朝のルーティンを習慣化し、成果を生み出していることを知りました。また、大きな成果は小さな行動の積み重ねから生まれることに気づきました。

**感情：** 私自身の経験から、良い習慣を継続することの難しさを実感しています。そのため、個人の意志力に依存するのではなく「小さな変化」を自然に積み重ねられる仕組みを提供し、多くの人の成長を支援したいと考えるようになりました。

## 2-2. なぜそれが「気になった」のか
**原体験：** 働きながら独学でプログラミングを学び、エンジニアへのキャリアチェンジに挑戦した際、仕事と学習の両立の過酷さを当事者として痛感しました。効率的な学習と習慣化の仕組みの必要性を誰よりも理解しているためです。

**価値観：** 「他者に貢献し助けることで、巡り巡って自分もより大きな成長というリターンを得られる（Giverの精神）」という信念があり、同じように限られた時間で未来を変えようと奮闘する人の力になりたいと考えたためです。

# 3. 課題の整理（核心への深掘り）

## 3-1. 表に見えている困りごと
* 朝のルーティンを毎日コツコツ継続できない。
* 朝活を始めても、すぐに三日坊主で終わってしまう。

## 3-2. 本当に解決したい課題は何か
**なぜ長続きしないのか？：** 多忙な日々を過ごす現代人は、エネルギーが残っていないことや、最初から高すぎる目標を立ててしまうため。
**なぜ高い目標だとダメなのか？：** 未達成になると完璧主義が邪魔をして「ゼロかヒャクか」の思考に陥るため。
**なぜ放棄してしまうのか？：** 挫折感や自己嫌悪がストレスとなり、行動そのものが苦痛になるため。
**本当に解決したい課題：** 「いい習慣が身に付かない自分」への挫折感や自己嫌悪を、個人の意志力ではなく「システム」の力で克服すること。

# 4. 想定ユーザーについて

## 4-1. ペルソナ設定
**年齢：** 30代（特に30代後半のキャリア転換期・リスタート層）。理由は、20代より可処分時間が減少し、朝活へのニーズが最も高い世代だから。
**生活状況：** 日中は仕事をこなしながら、早朝にエンジニア転職や起業を目指して学習している社会人。疲労度が高く、朝の時間を有効活用する必要がある。
**環境：** 起床直後のベッドの中でまだゴロゴロしていたい瞬間。エネルギーが低い状態でも実行できる極小の行動が求められる。

## 4-2. 自分とユーザーの距離
**距離感：** 自分自身／過去の自分。
**理由：** 仕事と並行してプログラミングを独学し、生活を変えようと努力してきた自身の経験と完全に一致するため。

## 4-3. 需要・存在確認
**初期ユーザー：** 朝の時間を変えて人生を変えたい社会人や学習者。
**思い出す瞬間：** 目覚めた直後、または前夜に「明日の朝こそ頑張ろう」と決意した時。
**既存の代替品：** Streaksなどの習慣トラッカー（1日でもサボると連続記録がリセットされる厳格な仕様）。
**代替品の課題と本アプリの優位性：** 既存アプリはタスク管理や厳格なトラッキングが中心ですが、本アプリは脳の抵抗をなくす「極小実践」と「挫折防止の仕組み」に特化しているため。

## 4-4. 導入・継続の流れ
**導入：** 意志力の限界を感じ、「仕組み」による自己変革を求めて登録。
**継続の仕組み：** 未達成が続いた場合は目標難易度を自動的に下げ、挫折とアプリからの離脱を防ぐ。

# 5. 既存サービス・競合調査

## 5-1. 似たサービスの調査
**サービス名：** Streaks
**概要：** ユーザーが良い習慣を形成・維持できるようサポートする、iOS/Appleエコシステムを中心としたミニマルな習慣トラッカー。

## 5-2. それでも自分が作りたい理由
Streaksはシンプルで多様な習慣を登録・達成できる優れたアプリです。しかし、1日でもサボると連続記録がリセットされる仕様であり、目標未達時にユーザーの離脱を防ぐシステムがありません。

私が開発する本アプリは「ルーティン」は、週3回の達成でタスク成功とみなし、毎日やらなければならないという強迫観念に陥ることなく継続できます。さらに、目標未達時でもユーザーの離脱を防ぐための「8段階の目標調整機能」を設け、ユーザーが脳に負担をかけずに継続できるアプリを目指しています。

## 5-3. 差別化を一文で決める
連続達成日数の厳格なリセットを排除し、目標の自動下方修正機能によって脳の抵抗を無くし、「極小行動」の定着に特化した習慣化アプリ。

# 6. このサービスで提供したい価値

**気持ち：** 小さな成功体験を積み重ねることで自己効力感が高まる。
**考え方：** 成果は意志力ではなく、仕組みと小さな積み重ねによって生まれると実感できる。

## 6-2. 価値を一文で表す

# 7. このアプリで実現すること

## 朝の極小ルーティン（タイムライン順）
最終的な目標時間（計60分）

* **1. 運動 (15分)** （最終目標：朝のジョギング・日光浴で体を覚ます ／ スモールスタート：玄関の前に10秒立つ）
* **2. 瞑想 (20分)** （最終目標：運動後の最高の脳状態で心を落ち着かせる ／ スモールスタート：深呼吸1回）
* **3. 読書 (20分)** （最終目標：研ぎ澄まされた脳で知識をインプット ／ スモールスタート：本を1ページ読む）
* **4. 1日計画・ジャーナリング (5分)** （最終目標：今日一日のスケジュールと優先順位を整理する ／ スモールスタート：今日やること1つ書き出す）

## MVPで作る機能
* **ユーザー認証・マイページ：** ユーザー登録、ログイン、人生の目標・ビジョン登録。
* **マイクロルーティン登録：** 4つのコア・ルーティンの登録とスモールスタートの設定。
* **8段階の目標ステップアップ機能：** ユーザーが最初から高すぎる目標を立てて挫折するのを防ぐため、極小レベルからスタートし、条件達成で自動昇格していく仕組み。
* **動的目標調整システム：** 週3回の実行でクリアとし、3日連続未達成時にシステムが自動で目標値を下方修正して挫折を防止。
* **ワンタッチ完了チェック機能：** 直感的に素早く行えるルーティンの完了チェック。
* **成長ダッシュボード：** ストリーク（連続達成日数）の可視化によるモチベーション維持。

## 「極小ルーティン」の基準を具体化
**朝の60分ルーティン：8段階の段階的目標上昇システム**

| レベル (Level) | 1. 運動 (最終 15分) | 2. 瞑想 (最終 20分) | 3. 読書 (最終 20分) | 4. 1日の計画 (最終 5分) | ステップのコンセプト |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Level 1** | 玄関の前に10秒立つ | 深呼吸 1回 | 本を 1ページ読む | 今日やることを 1つ書き出す | **スモールスタート（ハードルをゼロに）** |
| **Level 2** | 軽い足踏み 1分 | 瞑想 2分 | 読書 3分 | メモ帳で今日の予定を確認する | **行動開始（体を軽く起こす）** |
| **Level 3** | ストレッチ 3分 | 瞑想 5分 | 読書 5分 | 今日やることを 2つ書き出す | **習慣の固定（実行の定着）** |
| **Level 4** | ジョギング 5分 | 瞑想 8分 | 読書 8分 | 簡単な優先順位をつける | **時間拡張（初級フェーズ）** |
| **Level 5** | ジョギング 8分 | 瞑想 10分 | 読書 10分 | 主要なスケジュールの時間設定 | **リズム形成（中級フェーズ）** |
| **Level 6** | ジョギング 10分 | 瞑想 13分 | 読書 13分 | 一日のスケジュールの枠組みを作る | **没入誘導（上級フェーズ）** |
| **Level 7** | ジョギング 12分 | 瞑想 16分 | 読書 16分 | 詳細なタイムスケジュール配分 | **最終整備（完成へのステップ）** |
| **Level 8 (最終)** | **ジョギング 15分 (日光浴)** | **瞑想 20分 (最高の状態)** | **読書 20分 (深い没入)** | **一日のスケジュール完成 (5分)** | **完成期（朝の1時間を支配完了）** |

**レベルアップ条件 (Level Up Condition)**
各レベルにおいて、「週3回以上の成功」を2週間連続（または累計2週間）で達成した場合、自動的に次のレベルへ昇格します。焦らず確実に習慣を定着させ、次のステップへ進むための安全な設計です。

# 8. このアプリの懸念点とその対策
**懸念点：** 朝寝起きの状態では、習慣アプリを開くより、SNSや娯楽アプリを優先して開いてしまう可能性がある。
**原因：** どれだけ優れた機能でも、起動されなければ意味がないため。
**対策：** スマホの「ホーム画面へ自分の目標を追加（PWA）」機能とWebプッシュ通知を活用し、ネイティブアプリのように起床直後1タップでアクセスできる導線を設計する。

## 本サービスの概要
■ 目的・概要 本サービスは、厳格な管理ではなく、自らのペースで朝の成長を具現化する「適応型」ルーティン・習慣化アプリです。既存の厳格な習慣化アプリで生じがちな「いい習慣が身に付かない」という挫折感や、完璧主義による自己嫌悪を排除。極小の成功体験を自分のペースで積み重ねることで、ユーザーの自己効力感と持続可能な自己成長を後押しします。
■ 想定ユーザー 日中は仕事で多忙を極め、早朝の時間を使って自己研鑽（エンジニア転職や目標達成など）を目指すものの、疲労から三日坊主を繰り返してしまう30代の社会人。
■ 主な機能 脳の抵抗をなくす「極小実践」と「挫折防止」に特化した以下の機能を提供します。

極小ルーティンと8段階のステップアップ機能 「玄関の前に10秒立つ」「本を1ページ読む」といったハードルゼロのスモールスタートから開始。「運動・瞑想・読書・計画」の4大ルーティンを週3回、2週間継続することで自動的に次のレベルへ昇格します。
適応型セーフティネット（動的目標調整システム） 3日連続で未達成となった場合、システムが自動で目標難易度を下方修正します。連続記録の厳格なリセットによる燃え尽きや離脱を未然に防ぎます。
ワンタッチ完了チェック＆成長ダッシュボード 起床直後のエネルギーが低い状態でも、1タップで直感的に記録できるシンプルなUIを採用。ストリーク（連続達成日数）を可視化し、モチベーションを維持します。
